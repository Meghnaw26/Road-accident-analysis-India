# Road-accident-analysis-India

## Project Type: Data Analyst (EDA and Visualization)

## About Dataset: The data contains Road accident information for **50 cities** of India in the year **2020**

## Project Overview:
Exploratory data analysis of road accident reports focused on identifying patterns by location, cause, and outcome. The goal is to analyze the causes of road accidents in million-plus-cities in india, identify patterns in causes and outcomes and visualize the distribution of accidents based on different categories.

## Tools and Technologies 
- Python (pandas, numpy)
- Jupyter Notebook
- Visualization: matplotlib, seaborn
- Dashboarding: Tableau (storyboard / dashboard)

## Data Preprocessing 
- Performed an initial data audit to identify missing values, duplicates and inconsistent entries.
- Handled missing values: imputed numeric fields with median values.
